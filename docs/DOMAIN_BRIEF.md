# Domain brief

Independent founding-engineer application by Saran Vashisht for Saurav Shah
at ZeroGrunt. Public, synthetic-data presentation, not a company product.
The primary demonstration follows fictional printer maintenance invoice
000184, vendor PAPERCARE-01, entity NORTHSTAR-IN, INR 125000 minor units.

Four scenarios: context, recovery, correction, evaluation. Browser state lives
in memory and resets on reload. Separate processes prove durable HTTP behavior.
No live accounting, payments, uploads, OCR, employer data or external messages.
No claims of software-engineer tenure, production adoption or model quality
without direct evidence. Credit AI-assisted implementation.
